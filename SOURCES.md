# Design resources

- Reveal by asanshay, retrieved via authenticated 21st CLI, component 19240: https://21st.dev/@asanshay/components/reveal. Public component is MIT licensed. Adapted fade/blur, once-on-entry and stagger behavior to native IntersectionObserver/Web Animations; reduced motion and focus behavior added.
- PricingCards03 by ruixen.ui, retrieved via authenticated 21st CLI, component 4112: https://21st.dev/@ruixen.ui/components/pricnig-cards03. Used two-column annual pricing hierarchy and recommended-plan emphasis as a design reference; markup and styling implemented for this site.
- The black, white and gold redesign and decorative gold rings are original work for this site. Portfolio concepts have been removed at the user’s request.
- Additional 21st catalog search for black/gold hero inspiration surfaced Classy Hero by jatin-yadav05 and Hero Section Dark by kinfe123. No additional component source was retrieved for this redesign.
- Typography: DM Sans and DM Serif Display via Google Fonts.

- CR Digital logo supplied by the user: CRD Logo Transparent.png. Original retained in src/assets; display image trims transparent margins only. CSS inversion provides a light version on dark backgrounds.
- 3D scroll treatment extends the existing native Reveal adaptation. A fresh 21st search returned the same asanshay Reveal pattern; no additional component retrieval was needed.

- Desktop monitor frame and stand implemented in native CSS around the existing artwork. 21st search surfaced designali-in/Mac and saurabh-2607/Great UI Macbook Mockup as references; no source retrieved or new dependency added.
